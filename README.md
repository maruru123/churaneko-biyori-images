# ちゅらねこ日和 — 投稿画像置き場

[ちゅらねこ日和](https://churaneko.com/) が毎朝SNSに投稿する画像を置いています。
**画像はすべて自動生成**で、人の手で作ったものではありません。

Instagramの投稿APIが画像をURLで受け取る仕様のため、公開の置き場所として用意したリポジトリです。
生成する仕組み自体は別のリポジトリにあります。

## 中身

```
2026/08/02.jpg   その日に投稿した画像(1080x1350)
```
